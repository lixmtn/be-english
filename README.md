# Bé English

PWA offline cho iPad để 2 bé ôn tiếng Anh theo bài trên lớp.

- 🦖 Minh (2.5 tuổi): ít lựa chọn hơn, kéo từng mảnh một, có gợi ý phát sáng
- 🦄 Bé lớn (4 tuổi): nhiều lựa chọn hơn, phải nghe đúng tên bộ phận mới ghép được, có thêm phonics

Game theo bài: Ghép Gấu (body), Chạm vào, Học từ, Nghe & chọn, Lật hình (6/10/16 thẻ), Ghép bóng.
Phonics: ABC Explorer, ABC Parade, Tìm chữ, Bắt đầu bằng?, Chữ đầu tiên.

Phụ huynh: giữ ⚙️ 1 giây ở màn chọn bé → đổi tên, tốc độ đọc, **thêm bài trên lớp** (`từ | emoji | nghĩa`).

Chạy local: `python3 -m http.server 8791`. Không cần build. Thêm chủ đề cố định: sửa `data.js`. Đổi phiên bản: tăng `V` trong `sw.js`.
